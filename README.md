# 동탄2 C14 입주예정자 자료실

공개 주소: https://c14.ai-hub-os.com/ · 화면 업데이트: 2026-09-08
입주민 운영 사이트이며 LH 공식 홈페이지와 별개입니다.

## 실행·수정

- `python3 -m http.server 8764` → http://localhost:8764
- 입주민 생활 안내: `residents.html`, `styles.css`, `home.js`
- 첫 화면·조성원가 쟁점·향후 준비: `index.html`, `audit.css`, `app.js`
- 두 영역은 동일한 상단 메뉴로 이동합니다. `styles.css`는 공통 글꼴·메뉴도 포함합니다.
- 입주 일정·준비물·출처 쪽번호: `resident-timeline.json`
- 관련 기사: `news.json` (제목·발행일·언론사·원문 링크)
- 국감 자료: `data.json`, 비공개 Supabase `c14-audit` 저장소
- 학교·생활 지도: `neighborhood.json` (좌표·주소·학교 배치 설명·공식 출처)
- 날짜·거리 계산: `resident-guide.mjs`. 날짜는 한국시간, 거리는 기준점 사이의 직선거리입니다.
- 계산기: `calculator.mjs`. 버튼/키보드 ↑↓는 소수점 보존 후 1억 증감, 최소 0.
- GitHub Pages: `aihubos/c14`, main/root. 기존 audit.html 주소는 첫 화면으로 이동. 기존 생활 안내 해시와 인증 콜백은 residents.html로 연결합니다.

## 기사 참여와 연락처 (2026-09-08)

- 두 페이지 첫 화면에 채팅에서 참여 요청이 확인된 연합뉴스 기사 1건을 강조하고 기존 관련 기사 5건을 함께 제공합니다.
- 기사 원문으로 이동해 댓글·공감에 참여합니다. 사이트에서 반응을 자동 제출하지 않습니다.
- 댓글 수와 공감·추천 합계는 C14 프로젝트 `article-counts` 함수로 조회합니다. 네이버 기사 반응의 합계이며 조회 시각을 함께 표시합니다. 최대 1분 캐시, 방문·수치 새로고침·1분 뒤 탭 복귀 시 조회합니다. 조회 실패는 0으로 표시하지 않습니다.
- 함수 소스: `server/article-counts.ts`. 공개된 고정 기사 1건의 수치만 조회하고 데이터베이스를 사용하지 않습니다. 기존 JWT 검증을 유지합니다.
- 오늘·총 방문자는 두 페이지 최상단에 표시합니다. 문의·자료 추가 요청은 사용자가 제공한 카카오톡 오픈채팅 링크로 연결합니다.
- 원본 채팅 CSV와 대화 참여자 정보는 공개 저장소에 포함하지 않습니다.
